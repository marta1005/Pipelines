\section{Introduction}
\label{sec:intro}

This report documents the full validation of surrogate models for use case \textbf{UCFATIGUE\_1}. 2 model architecture(s) were trained and evaluated: MLP, GradientBoosting. Each model predicts 7 structural output quantities from 8 input features (FLAP, Altitude, TAS, Mass, q, gamma, Type\_segment, Xcg(\%CMA)). The accuracy criterion requires the 90th-percentile relative error (Q90) to remain below 10\% for every output on unseen test data.

\section{Model Selection}
\label{sec:selection}

\textbf{GradientBoosting} achieved the highest average R\textsuperscript{2} on the test set (0.9643), outperforming MLP (R\textsuperscript{2}=0.5237). It is the recommended model for deployment.

\section{Accuracy Assessment (Q90 \& R\textsuperscript{2})}
\label{sec:accuracy}

\textbf{GradientBoosting} satisfies Q90 on 5/7 outputs. Passing: 1g, Vertical maneuver, Vertical gust, Turn, n0. Failing: \textcolor{red}{\textit{Frontal gust, Giro}}. Refer to the Improvement Roadmap for targeted corrective actions.

\section{Overfitting Assessment (KS Test)}
\label{sec:ks}

The Kolmogorov--Smirnov test compares residual distributions on train vs test sets. $H_0$: both distributions are identical (no overfitting). $p < 0.05$ is statistical evidence of overfitting.

The KS test detects distributional differences for \textbf{GradientBoosting} on: \textcolor{red}{\textit{1g, Vertical gust, Turn, n0, Giro}}. This suggests localised overfitting on these outputs. Increasing regularisation or reducing model capacity is recommended.

The VTP analysis confirms the test set is well-distributed within the training space (residual voxel proportion $\leq 0.05$, no isolated test points). The chi-squared test validates the split is statistically unbiased. Train/test partition is of high quality.

\section{Improvement Roadmap}
\label{sec:roadmap}

Prioritised actions based on the failure analysis above.

\begin{itemize}[leftmargin=1.4em,itemsep=3pt,topsep=3pt]
  \item \textbf{Significant failures} (\textit{Frontal gust, Giro}): Q90 exceeds target by $\geq 5\%$. Investigate input features and model capacity. Review whether additional physical drivers are missing from the input feature set, or consider a more expressive architecture (deeper network, ensemble).
  \item \textbf{Overfitting detected} (\textit{1g, Vertical gust, Turn, n0, Giro}): KS test rejects equal residual distributions on train and test. Increase regularisation (dropout, weight decay, early-stopping patience) or reduce model capacity.
\end{itemize}
