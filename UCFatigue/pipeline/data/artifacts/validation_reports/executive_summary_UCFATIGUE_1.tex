\section{Introduction}
\label{sec:intro}

This appendix documents the full validation of surrogate models for use case \textbf{UCFATIGUE\_1}. A total of 2 model architecture(s) were trained and evaluated: MLP, GradientBoosting. The models predict 7 output quantities (1g, Vertical maneuver, Vertical gust, Turn, Frontal gust, n0, Giro) from 8 input features (FLAP, Altitude, TAS, Mass, q, gamma, Type\_segment, Xcg(\%CMA)). The accuracy criterion requires that the 90th-percentile relative error (Q90) remains below 10\% for every output.

% ── 1. Model Selection ────────────────────────────────────────────────────────
\section{Model Selection}
\label{sec:selection}

\textbf{GradientBoosting} achieved the highest average R\textsuperscript{2} on the test set (0.9643), outperforming MLP (R\textsuperscript{2}=0.5237). It is therefore the recommended model for production deployment.

% ── 4. Overfitting Assessment ─────────────────────────────────────────────────
\section{Overfitting Assessment (KS Test)}
\label{sec:ks}

The Kolmogorov--Smirnov (KS) test compares the empirical distribution of
training residuals with that of test residuals.
$H_0$: both distributions are identical (no overfitting).
A p-value below 0.05 provides statistical evidence of overfitting.

\vspace{4pt}
The KS test detects distributional differences between train and test residuals for \textbf{GradientBoosting} on the following outputs: \textcolor{red}{\textit{1g, Vertical gust, Turn, n0, Giro}}. This suggests localised overfitting. Increasing regularisation or reducing model capacity for these outputs is recommended before deployment.

% ── 5. Data Split Quality ─────────────────────────────────────────────────────
\section{Data Split Quality (VTP Analysis)}
\label{sec:split}

The Voronoi Tesselation Proximity (VTP) method evaluates whether the test
set is representative of, and well-covered by, the training distribution.
A low residual voxel proportion indicates that test points are not isolated
outside the training space.

\vspace{4pt}
The Voronoi Tesselation Proximity (VTP) analysis confirms that the test set is well-distributed within the training space (residual voxel proportion $\leq 0.05$, no isolated test points). The chi-squared test ($p \geq 0.05$) validates that the split is statistically unbiased. The train/test partition is of high quality.

% ── 6. Improvement Roadmap ────────────────────────────────────────────────────
\section{Improvement Roadmap}
\label{sec:roadmap}

The following actions are prioritised based on the failure analysis above.

\begin{itemize}[leftmargin=1.4em,itemsep=3pt,topsep=3pt]
  \item \textbf{Significant failures} (\textit{Frontal gust, Giro}): Q90 exceeds target by $\geq 5\%$. Investigate input features and model capacity. Consider whether additional physical drivers of these outputs are missing from the input feature set, or evaluate a more expressive architecture (e.g.\ deeper network, ensemble).
  \item \textbf{Overfitting detected} (\textit{1g, Vertical gust, Turn, n0, Giro}): KS test rejects equal residual distributions on train and test. Increase regularisation strength (dropout rate, weight decay, early-stopping patience) or reduce model capacity.
\end{itemize}
